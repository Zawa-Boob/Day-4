Pernyataan Privasi dan Pengumpulan Data

Untuk menjaga keamanan lingkungan sekolah, kami mengumpulkan data pribadi Anda meliputi Foto Wajah dan Foto Identitas (KTP/SIM).

Sesuai dengan UU No. 27 Tahun 2022 tentang Pelindungan Data Pribadi:

  • Data ini hanya digunakan untuk keperluan verifikasi tamu oleh Kepala Sekolah dan keamanan internal.
  • Data Anda akan dienkripsi dan disimpan secara aman di server kami.
  • Data akan dihapus secara otomatis (retensi) setelah 90 hari kecuali diperlukan untuk investigasi.
  • Kami tidak akan menjual atau membagikan data Anda kepada pihak ketiga manapun.
